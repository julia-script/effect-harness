# effect-harness

The package exposes embedded durable conversations, typed documents and checkpoint tasks using Effect services. `Harness.layer` captures Persistence and Executor, and the Executor captures the model catalogue and tool registry.

Use root namespaces or leaf imports. Storage adapters, coding tools and native API-key provider adapters have dedicated subpaths. [Modules and services](../reference/packages.md) lists their contracts.

Start with the [offline tutorial](../tutorials/first-conversation.md), then compose [providers](../providers.md), [tools](../tools.md), [tasks](../tasks.md) and [persistence](../persistence.md).
